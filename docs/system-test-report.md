# Отчет по system-тестам

**Дата прогона:** 27.11.2026  
**Команда:** `make test-system`  
**Итог:** 138 пройдено, 8 упало, всего 146 тестов. Прогон неуспешен.

## Что проверяет system-прогон

`make test-system` поднимает тестовый стек Docker Compose и проверяет сервисы
как работающую систему, через их HTTP API и тестовую PostgreSQL-базу
`aiesec_test`. Перед запуском тестов инициализируются роли и схемы БД;
для тестов создаются синтетические записи каталога.

Это интеграционный уровень: тесты проверяют взаимодействие backend, matcher,
parser и PostgreSQL. Это не замена unit-тестам. В частности, API-тесты парсера
не запускают реальную синхронизацию с AIESEC и не используют внешний токен.

### Неуспешные проверки

1. **Ограничение размера тела запроса:** запрос профиля размером больше 64 КБ
   получил `200`, ожидался `413`.
2. **Проверка дат:** некорректное значение `from=abc` на `/history` и
   `/analytics/me` вернуло `500`, ожидался `422` (две проверки).
3. **Валидация отзыва:** невалидный `run_id` (`"abc"`) вернул `500`,
   ожидался `422`.
4. **Валидация фильтра рекомендаций:** числовое значение вместо списка
   `filters.exclude_opportunity_ids` вернуло `500`, ожидался `422`.
5. **Ответ рекомендаций:** поле `strategy` вернуло `null`, ожидалось
   `"weighted_v1"`. Проверка `total_candidates` после этого утверждения
   не выполняется, поэтому ее результат этим тестом не установлен.
6. **Настройки дашборда:** `GET /users/me/dashboard-preferences` вернул `404`,
   тест ожидает `200`.
7. **Статус при отсутствии согласия:** сохранение профиля вернуло `409`,
   тест ожидает `403`. Это расхождение контракта теста и API; необходимо
   определить ожидаемый статус и привести реализацию или тест к нему.

## Предупреждения

- В `qa/catalog_data.py` используется устаревающий `datetime.utcnow()`;
  рекомендуется перейти на timezone-aware UTC-время.
- `pytest-asyncio` сообщает, что не задан `asyncio_default_fixture_loop_scope`.

## Вывод

Большинство интеграционных сценариев прошло, включая запуск сервисов,
контракты БД и основные пользовательские потоки. Однако системный набор пока
не является зеленым: шесть проверок связаны с ограничением размера запроса,
обработкой невалидного ввода или неполным ответом API; одна — с отсутствующим
endpoint, еще одна — с несогласованностью статуса согласия. Перед релизом
нужно устранить ошибки и повторить `make test-system`.
